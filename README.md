# 🧱 Infiniminer-game-v2

A modernized and extended version of the classic voxel-based mining game **Infiniminer**. Built in C# using the original Infiniminer codebase, this version brings new gameplay modes, partial modding support, and a roadmap for future improvements.

> 🎮 **Play. Mine. Build. Compete.** The voxel world is back and better than ever.

## 🚀 Features

- 🎮 **Multiple Game Modes** – Choose from a variety of gameplay types like Free Build, Competitive Mining, and Time Trials (more coming soon!)
- 🔧 **Partially Moddable** – Tweak textures, maps, and some game logic to create your own experience
- 👥 **Multiplayer Ready** – Set up your own local or online multiplayer sessions (basic support)
- ⚙️ **Optimized Codebase** – Cleaned-up C# code for better readability and modifiability
- 🖥️ **Cross-platform Potential** – Future-proof structure for Windows, and potential Linux/macOS support

## 🧰 Tech Stack

- 💻 Language: **C#**
- 🧱 Base Engine: Original **Infiniminer** open-source code by Zachtronics
- 🛠️ Build System: Compatible with Visual Studio (.NET Framework)
